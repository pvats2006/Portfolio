# Priyanshu AI Portfolio (React + Vite)

Production-style single-page AI/ML themed portfolio built with React, Vite, Tailwind CSS, Framer Motion, Three.js, Recharts, and tsParticles.

## Run Locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
